# Wedding Background Music (Tamil Wedding Song)

Place your desired Tamil wedding song MP3 in this folder:

```
public/assets/audio/wedding-bgm.mp3
```

### Supported Format
- File name: `wedding-bgm.mp3`
- Format: MP3 (Standard audio/mpeg) or M4A / AAC
- Recommended length: 2 to 4 minutes (the audio automatically loops seamlessly)

### How It Works:
1. When the guest taps **"Open Invitation"** on the initial envelope card, the song starts playing automatically.
2. The user can mute or unmute anytime using the floating **Music button** at the top right of the screen.
3. If no MP3 file is placed here, the app gracefully falls back to an auspicious synthesized temple Tanpura drone soundscape.
